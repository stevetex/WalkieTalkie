# 15-morticia — Morticia

PORCELAIN ivory housing, lots of long center-parted flowing dark black hair wrapping both sides and trailing at base, eyelashes and subtle indigo eyeshadow, antenna peeking out above hair.

- `master.png`: native transparent master.
- `app/CharacterArt.xcassets`: importable 1×/2×/3× imageset named `OAOMorticia`, at 256 points.
- `merch/color-300dpi.png`: same native pixels with 300 DPI metadata.
- `icons/icon-1024.png`: opaque square icon source for both platforms.
- `icons/iPhone.xcassets` and `icons/Watch.xcassets`: target-specific catalogs; app icon set `OAOMorticiaIcon`.
- `icons/exports`: convenience sizes for previews.

See the parent README for integration, print limits and provenance.
