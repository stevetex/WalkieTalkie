# 05-bunny — Bunny

porcelain ivory housing, two rabbit-ear antennas with muted rose pink interiors, two ivory buck teeth descending into round speaker mouth.

- `master.png`: native transparent master.
- `app/CharacterArt.xcassets`: importable 1×/2×/3× imageset named `OAOBunny`, at 256 points.
- `merch/color-300dpi.png`: same native pixels with 300 DPI metadata.
- `icons/icon-1024.png`: opaque square icon source for both platforms.
- `icons/iPhone.xcassets` and `icons/Watch.xcassets`: target-specific catalogs; app icon set `OAOBunnyIcon`.
- `icons/exports`: convenience sizes for previews.

See the parent README for integration, print limits and provenance.
