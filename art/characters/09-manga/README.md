# 09-manga — Manga

porcelain ivory housing, very large tall oval manga eyes with several bright ivory highlights and stars, filling upper face, as large as approved sheet.

- `master.png`: native transparent master.
- `app/CharacterArt.xcassets`: importable 1×/2×/3× imageset named `OAOManga`, at 256 points.
- `merch/color-300dpi.png`: same native pixels with 300 DPI metadata.
- `icons/icon-1024.png`: opaque square icon source for both platforms.
- `icons/iPhone.xcassets` and `icons/Watch.xcassets`: target-specific catalogs; app icon set `OAOMangaIcon`.
- `icons/exports`: convenience sizes for previews.

See the parent README for integration, print limits and provenance.
