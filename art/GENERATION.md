# Over&Out artwork provenance

Created September 27, 2026 using the built-in image-generation tool. Approved reference: option 09, Chrome Tomorrow, with rotary knob eyes and a circular speaker mouth. No CLI fallback was used.

Each production illustration was generated from the approved image or the resulting mascot master. Generated adaptations retain the design but are not pixel-identical composites. The reference board is preserved under `reference/`.

PNG exports were copied or downsampled with macOS `sips`; no artificial resolution increase was applied. Merchandise copies carry 300 DPI metadata. Catalogs and documentation were packaged separately; app source and project settings were not changed.

Two transparent ivory stacked-wordmark attempts were discarded because of edge artifacts. The finished stacked artwork uses an opaque indigo background; use the separate transparent mascot for adaptive screen layouts.
